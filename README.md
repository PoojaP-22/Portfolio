# Pooja P. — Developer Portfolio

A personal developer portfolio built with **React + Vite**, showcasing my projects, hackathon achievements, technical skills, and developer journey through a dark pixel-inspired interface.

## Run Locally

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```

## Tech Stack

React · Vite · JavaScript · CSS · React Icons

## Featured Projects

* **MetalliSense** — Industrial AI and machine learning platform for metallurgy decision support.
* **FloatChat** — AI-powered conversational interface for marine and oceanographic data.
* **Legal Query AI** — RAG-based legal document question-answering system using semantic vector search.
