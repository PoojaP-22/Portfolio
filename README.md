# Pooja P. — Developer Portfolio

A responsive, light-themed personal portfolio built with **React 18 + Vite**. It presents selected software projects, engineering case studies, hackathon recognitions, technical skills, and contact details.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Stack

- React 18
- Vite
- JavaScript
- Custom responsive CSS
- React Icons (existing dependency)

## Portfolio sections

- Intro and availability
- About and engineering principles
- Filterable projects with case-study details
- Hackathons and event photographs
- Categorized technical toolkit
- Developer journey
- Contact links and email form

## Before publishing

1. Add a current PDF resume under `public/` and connect the download link.
2. Replace provisional journey milestones with verified education, internship, and experience dates.
3. Confirm public demo/repository URLs for each featured project.
4. Confirm project statuses and any claims such as patent filing or awards.
5. Run `npm run build` and review the site on mobile and desktop.
